# Sponsor Cognoscenti

Cognoscenti is the leading benchmark for evaluating cognitive memory systems inspired by human memory architectures like ACT-R. Your sponsorship helps us advance the field of emergent memory systems and build better AI memory layers.

## Why Sponsor Cognoscenti?

- **Industry Leadership**: Position your brand at the forefront of cognitive memory research
- **Developer Reach**: Connect with thousands of AI/ML developers building memory systems
- **Technical Excellence**: Support the only benchmark focused on selective remembering and useful forgetting
- **Open Source Impact**: Contribute to a project that's defining standards for cognitive memory evaluation
